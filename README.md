# DIO - Estudos e Desafios de Projetos

Repositório centralizador dedicado à documentação de projetos práticos, laboratórios e anotações desenvolvidas ao longo dos bootcamps e cursos da [Digital Innovation One (DIO)](https://www.dio.me/).

O objetivo deste espaço é registrar o aprendizado contínuo, boas práticas de automação, arquitetura de soluções e integração com Inteligência Artificial.
